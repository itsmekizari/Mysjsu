# Follower Dodge

A small mobile-friendly browser game prototype inspired by the mechanic where a player moves through a crowd and nearby characters dodge around them.

## Features

- Touch drag on mobile
- Mouse drag on desktop
- Crowd following
- Collision avoidance
- Side-step dodge behavior
- Modular JavaScript files
- GitHub Pages friendly

## Run locally

Open `index.html` in a browser, or use a simple local server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files while keeping the folder structure.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/root`.
6. Save and wait for the Pages URL.

No backend is required.
